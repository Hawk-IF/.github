# Hawk-If
O Hawk If é um sistema de gerenciamento de salas
automatizado que funciona atraves de sensores colocados 
em cada sala, ele permite ver o status de um sala e agendar seu uso
junto a um genrenciamento de seus recursos 

## Repositorios
O projeto é dividido em 5 repositorios
- [.Github](https://github.com/Hawk-IF/.github) responsavel pela visão publica do sistema
- [Frontend](https://github.com/Hawk-IF/Hawk-IF-Frontend) responsavel pelas telas web do sistema
- [Backend](https://github.com/Hawk-IF/Hawk-IF-Backend) responsavel pela logica de controle e gerenciamento dos sensores
- [Infra](https://github.com/Hawk-IF/Hawk-IF-Infra) responsavel pelos detalhes de infra
- [Docs](https://github.com/Hawk-IF/Hawk-IF-Docs) responsavel pela documentação
